# Zinco Mabati Rolling Mills Factory Website

## Open the website
1. Extract `zinco-mabati-website.zip`.
2. Open the extracted `zinco-mabati-website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension and choose **Open with Live Server**.
4. Keep the folder structure intact. The CSS, JavaScript and image paths are relative.

## Files
- `index.html` — complete responsive company website.
- `css/style.css` — styling, layout and mobile responsiveness.
- `js/products.js` — product names and indicative price ranges.
- `js/main.js` — navigation, product rendering and WhatsApp enquiry form.
- `admin.html` — local demonstration product editor.
- `images/zinco-price-list-poster.jpeg` — supplied Zinco promotional poster.

## Important notes before publishing
- The price ranges are indicative and have not been confirmed as official factory quotations. Verify them with the factory before going live.
- Replace the poster-based hero/gallery image with real, high-resolution factory and product photographs when available.
- The enquiry form opens WhatsApp with a pre-filled message. It does not save enquiries to a server.
- The product editor at `admin.html` is only a local browser demo. Demo PIN: `1234`. It stores changes in that browser only. It is not secure and does not update other visitors' devices. A production admin dashboard requires a backend, secure authentication and a database.
- Confirm the phone number, address, product specifications, delivery terms and current prices before publishing.
- The site uses Google Fonts from the internet; it will use a fallback font if offline.
